# Projeto IMC

Calculadora do Índice de Massa Corporal.

## Arquivos
- index.html
- style.css
- script.js
- app.py

## Como usar
1. Abra o index.html no navegador.
2. Digite o peso em kg e a altura em metros.
3. Clique em Calcular IMC.

## Python
python3 app.py

## Fórmula
IMC = peso / (altura * altura)
